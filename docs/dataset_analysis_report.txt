# TripOn 2.0: Comprehensive Dataset Analysis Report

This report summarizes the source, characteristics, and normalization of all datasets used in the TripOn 2.0 project, including the recent nationwide data expansion.

---

## 1. Primary Source Datasets (Data Lake)

These datasets formed the foundation of the project.

### A. Datafiniti Datasets (Three sources)
- **Content:** Large-scale hotel reviews, metadata, and geolocation data.
- **Characteristics:** Highly populated with metadata (latitude/longitude, categories), but contain significant duplicate reviews (up to 90% in some sources based on date/text).
- **Processing:** Deduplicated based on review content and date, normalized to a 1-5 rating scale.

### B. TripAdvisor Dataset
- **Content:** 20,491 clean, unformatted user reviews.
- **Characteristics:** Minimal metadata; primarily text and a 1-5 integer rating.
- **Processing:** Directly ingested into the review pipeline for sentiment extraction.

### C. General_Hotel_Reviews
- **Content:** 7,001 entries with unstructured rating attributes.
- **Characteristics:** Contains both qualitative ("Best service") and quantitative ("9 out of 10") data.
- **Processing:** Parsed to extract text and normalize 1-10 scores to the 1-5 standard.

### D. La_Veranda Dataset
- **Content:** 1,523 reviews focused on specific apartment properties.
- **Characteristics:** High missing values in `PositiveReview` and `NegativeReview` fields.
- **Processing:** Used as a test case for aspect-based parsing, filtering incomplete rows.

---

## 2. Synthetic Expansion Dataset

### Synthetic_Indian_Data
- **Purpose:** To bridge gaps in geographic coverage.
- **Methodology:** Generated synthetic data (`synthetic_indian_hotel_data.csv`) to ensure representation for all 36 Indian states and Union Territories (baseline of 5 hotels per region).
- **Alignment:** Schema is strictly aligned with the master dataset to allow unified database migration.
- **Sample Record Structure:**
  `{'hotel_name': 'Synthetic Visakhapatnam Hotel 1', 'city': 'Visakhapatnam', 'province': 'Andhra Pradesh', 'country': 'India', 'latitude': 17.6868, 'longitude': 83.2185, 'review_text': 'Great stay in Visakhapatnam, Andhra Pradesh!', 'rating': 4.5, 'data_source': 'Synthetic_Generator'}`

---

## 3. Data Integrity & Normalization Summary

- **Normalization:** All ratings mapped to [1.0, 5.0].
- **Deduplication:** Aggressive removal of duplicates based on `review_text` + `date` across all sources.
- **Geographic Integrity:** All locations validated against the `locations` database schema to ensure referential integrity.
- **Final Dataset Composition:** ~148k+ normalized reviews, enabling high-precision sentiment analysis.
