# TripOn 2.0: Dataset Analysis Report

This document summarizes the current data foundation for TripOn 2.0.

---

## 1. Data Foundation
- **Master Dataset (`master_indian_hotel_data.csv`):** Unified, deduplicated, and normalized dataset containing ~148k+ reviews from primary sources (Datafiniti, TripAdvisor, etc.). All ratings are normalized to a [1.0, 5.0] scale.
- **Geographic Expansion (`synthetic_indian_hotel_data.csv`):** Synthetic dataset generated to ensure nationwide coverage, providing at least 5 hotels per Indian state/UT, aligned with the master schema.

---

## 2. Normalization & Integrity
- **Normalization:** All ratings are normalized to a [1.0, 5.0] scale.
- **Deduplication:** Aggressive deduplication performed based on review content and date across all sources.
- **Referential Integrity:** All records are mapped to validated entries in the `locations` table.

---

## 3. Data Structure (Supabase)
- **Tables:**
  - `locations`: Unique city/province/country indices (2,276 entries).
  - `hotels`: Master hotel profiles with pre-computed sentiment metrics (4,835 entries).
  - `reviews`: Granular, processed reviews linked via foreign keys (148,844 entries).
